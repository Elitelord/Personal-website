# My experience
To start off, I began by developing an understanding of machine learning and specifically how GAN models work. The principal investigator on this project gave me an input data set with the PUF challenge and response pairs for a correct output. 
My first step was to explore this dataset to understand its basic components and how the data looked. After playing around with it, I decided to normalize the dataset in order to feed it into a GAN model. Then I wrote the model’s code and started training it. After training the model to classify fake and real responses, I generated a confusion matrix to evaluate the accuracy of the predictions. The predicted label of false(0) or true(1) is on the bottom while the left shows the true label for each. The model is decently accurate as a majority of the labels are predicted correctly.
